# Lumen — Agentic Data Intelligence Platform (PRD)

## Original Problem Statement
User's repo is **Lumen**, a React + FastAPI + Postgres multi-agent data platform.
Request: *"test end-to-end all the things are generating or not and add Groq support also and all the things are functional, any fixes please check and push to the same branch"*.

Working branch: **`updated-features`**.

## Architecture
- **Frontend**: React 18 + Vite 5 + TypeScript (Tailwind + shadcn/ui + lucide-react).
- **Backend**: FastAPI (Python 3.11), in-process async task runner (Celery-compatible facade), in-memory TTL cache.
- **Storage**: PostgreSQL 15 (warehouse + dataset registry). In-memory CacheService (not Redis).
- **LLM**: `emergentintegrations` universal key covers OpenAI/Anthropic/Gemini. `litellm` direct path covers **Groq** (new).
- **Realtime**: SSE for chat, WebSocket at `/api/v1/ws/pipeline` for agent pipeline.

## User Personas
- **Data analyst** — uploads CSV/JSON/Parquet, asks NL questions, exports dashboards.
- **Engineering lead** — compares datasets, profiles quality, audits LLM usage in Settings.
- **Executive** — consumes Reports + Insights generated by the agent pipeline.

## Core Requirements (static)
1. Upload + ingestion of CSV/JSON/Parquet/Excel ≤500 MB.
2. Multi-agent pipeline (ingestion → EDA → insight → visualization → report).
3. LLM-backed insights, NL→SQL query, chart/dashboard generation.
4. Multi-provider LLM with runtime switcher (OpenAI, Anthropic, Gemini, **Groq**).
5. End-to-end telemetry surfaced in Settings.
